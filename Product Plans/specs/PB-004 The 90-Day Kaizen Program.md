# Build spec — PB-004 The 90-Day Kaizen Program (v1)

Brief: `2026-09-12 Product Plan.md` §"Launch product briefs" → PB-004 · Brand kit: `brand-kit.md` v1 · Owner decisions pending: brand name; whether "Kaizen" survives the owner's legal check (see Risks)

**What it is:** a 70-page designed program workbook plus a pin-up wall tracker, built around floors, restarts and a day-21 milestone. **$24 (launch $19).** It answers the clearest design gap in the research: *Live Intentionally* sells 13,089 copies at $19.99 with a tracker so plain it only appears in a buyer's photograph.

**Accent colour for this family:** sage `#7C9A7E`.

> **Naming note.** "Kaizen" is a generic Japanese word (改善, "continuous improvement") and we use it descriptively. KAIZEN marks exist in unrelated classes (software, cookware, toys); no Class 16 planner registration surfaced in our screen. **This is a search screen, not clearance — the owner should have it checked before print.** Fallback name if it fails: "The 90-Day Program: small steps, kept."
>
> **Claims rule.** Behavioural only. No weight-loss, medical, sleep-disorder or mental-health claims — that is exactly where the category leader takes on risk. Sample content must never model a calorie target, a weight goal or a medication routine.

## Page setup

Margins 15 mm · 3-column grid · daily rows 7 mm on tracker pages, writing lines 7.5 mm elsewhere · Fraunces titles 26 pt / section 17 pt / italic accent 13 pt · Source Sans 3 body 10.5 pt · IBM Plex Mono for all day numbers, counts and dates · sage as the section colour, brass reserved for milestones only · running header: phase name left, `90-DAY KAIZEN` right

**Three phases:** Days 1–21 *Build* · Days 22–60 *Keep* · Days 61–90 *Own*. Phase dividers carry a short honest note about what usually goes wrong in that phase.

**Wall tracker (separate A3 file):** 90 numbered cells in a 3-row × 30-column grid, one strip per habit (3 strips), three-state marks, milestone markers at 21/45/90 in brass, the three habits written at the top, the floor version printed *beside* each habit name (so the floor is visible at the moment of marking — this is the design point), and a single line at the base: *"A row of floors through a bad month is the win."*

## Hyperlink / tab map (digital)

- **Tab rail:** `START · SETUP · PHASE 1 · DAY 21 · PHASE 2 · DAY 45 · PHASE 3 · DAY 90 · REVIEWS · RESTART · SPARES`.
- **The Restart Page is linked from every single day-grid page and every weekly review page** — a buyer must never have to search for it at the moment they need it. This is the most important link in the product.
- Day grids link forward to their phase checkpoint; checkpoints link back to the habit design page (p.9) so a redesign is one tap away.
- Weekly reviews run in a ring W1→W13.
- Outbound: p.36 → PB-005, PB-002.
