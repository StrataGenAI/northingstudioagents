**Purpose:** the whole plan on one sheet, so it can be pinned up.
**Layout:** title block top with the compass device small, top-right, brass
marker on N; then five stacked blocks; disclaimer and running footer at the foot.

**Links:** none.

**Block proportions.** The spec's Layout column sketches "5 stacked blocks at
1 / 3 / 3 / 3 / 1 proportions"; its Writing space column specifies 2 / 3 / 3 / 3 / 2
ruled lines. These do not agree — a literal 1/3/3/3/1 height split would leave
blocks 1 and 5 too short for the two lines each is required to carry. The
concrete instruction (line counts) is built, and the *shape* of 1/3/3/3/1 is kept:
blocks 1 and 5 are visibly the short ones, 2–4 the tall ones. Recorded as an open
question in `BUILD-LOG.md`.

## Page 2 — How to use it + what's next

**Purpose:** remove friction, then point up the ladder — honestly.
**Layout (changed in round 2):** title block top; five full-width steps beneath;
the cross-sell as a full-width band at the foot, its link set in its own outlined
panel.

The spec's Layout column asks for "Two columns: left 'How to use', right 'If you
want more'". It was built that way in round 1, and the round-1 critique measured
the result: **111.4 mm — 37.5% of the A4 sheet — of empty paper in the right
column**, with the brand device grown to 46 mm and parked at its foot to stop the
column ending half-way. The cross-sell copy is roughly a quarter the length of
the steps copy, so two columns stretched to the same height cannot both be full.

The two zones the spec names are unchanged and still in the spec's order — how to
use first, what's next second — but stacked rather than set side by side, which
also gives the one outbound link the width to be set at a size a buyer can read
and retype. **No copy changed.** Recorded as a deviation in `BUILD-LOG.md`
round 2 and raised there as an owner question.
