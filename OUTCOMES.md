# Outcomes — what happened after listing

**The owner fills this in by hand.** The easiest way is GitHub's web editor. Commands
run `git pull` before any agent reads this file.

`niche-scout` and `product-planner` read it **before** they produce anything. With no
rows, they must say "no outcome data yet". They never estimate, extrapolate or
invent a number.

**How to fill it in:**
- Add a row when a listing goes live.
- Fill in the 14-day and 30-day columns on those days.
- Use numbers from the platform dashboard only.
- Write `n/a` where a platform has no such metric (Gumroad has no favourites).
- Leave a cell blank if it isn't known yet.

**Columns:**
- **product:** customer-facing name (as in `catalogue.md`)
- **line:** product line (`quiet-compass`, …)
- **niche:** niche as named in the niche-scout shortlist
- **date_listed:** YYYY-MM-DD
- **platform:** `gumroad` or `etsy`
- **views_14d, favourites_14d, sales_14d:** totals for the first 14 days
- **views_30d, favourites_30d, sales_30d:** totals for the first 30 days
- **notes:** anything that explains the numbers (price change, a Pinterest pin that took off, a refund)
